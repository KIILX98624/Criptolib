# 🔐 Criptolib

A Python library that provides a collection of cryptographic tools and algorithms, organized into multiple sub-libraries.

Criptolib aims to bring together different encryption and cryptographic algorithms based on widely used and modern standards, providing a simple and organized interface for developers.

## ✨ Features

* 🔒 Multiple cryptographic algorithms
* 📚 Organized into specialized sub-libraries
* 🐍 Written in Python
* ⚡ Simple and developer-friendly API
* 🛡️ Based on established cryptographic standards
* 🔧 Designed to be easily extended with new algorithms

## 📦 Requirements

* Python **3.10** or newer

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/KIILX98624/Criptolib.git
```

Enter the project directory:

```bash
cd Criptolib
```

Then import Criptolib into your Python project:

```python
import criptolib
```

## 💻 Usage

Example:

```python
from criptolib import ...
```

## ⚠️ Security Notice

Criptolib is an educational and development project.

Cryptographic software can be extremely sensitive to implementation details. **Do not use Criptolib in production or for protecting sensitive information unless the specific algorithms and implementations have been properly reviewed and tested.**
